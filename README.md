Quantile forecaster for GTA VI's launch-day Twitch viewers, hour by hour. Anchors on the hour-1 print and scales it with the ratio curve learned from 42 past big game launches, with per-hour log-spreads calibrated for honest 90% coverage. Backtested on 4 practice launches: mean pinball loss 0.16 vs 0.39 for the house baseline.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
